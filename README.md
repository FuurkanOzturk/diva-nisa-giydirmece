# Diva Dress & Makeup

Nisa & Furkan giydirme oyunu. Bu klasor GitHub Pages icin hazirlanmis
surumdur; `deploy_hazirla.bat` tarafindan uretilir, elle duzenlenmez.

## Yayinlama

1. Bu klasorun **icindekileri** deponun koku olacak sekilde yukle.
2. Depo > Settings > Pages > Source: `Deploy from a branch`,
   Branch: `main` / klasor: `/ (root)`.
3. Birkac dakika sonra adres hazir olur.

## Telefonda cevrimdisi oynamak

Adresi Safari ile ac, oyun tam yuklenene kadar bekle (ilk acilis tum
gorselleri indirir), sonra Paylas > Ana Ekrana Ekle. Bundan sonra
internet olmasa da acilir.
